# eval/embedding/v2: the enlarged NL eval

Design: `docs/design/GM-460-enlarged-nl-eval.md`. v2 is a new version of the
instrument, not an extension of GM-398's decision set: no int8-vs-fp32
decision is taken on it.

## Layout

| path | what |
|---|---|
| `corpora.toml`, `variants.toml`, `queries/mechanical` | symlinks to the GM-398 files |
| `queries/<corpus>.jsonl` | generated by `build.py`, committed: GM-398 file bytes, then GM-422 confirm file bytes, then `new/queries/<corpus>.jsonl` bytes, each verbatim |
| `new/targets/<corpus>.jsonl` | seed-460 target lists (`sample.sh`), disjoint from both earlier studies' consumed targets and expected symbols |
| `new/targets/<corpus>.skips.jsonl` | targets the author skipped: one `{"n", "qualifiedName", "reason"}` per line |
| `new/queries/<corpus>.jsonl` | GM-460 authored queries, ids `<prefix>-eNNN` |
| `work/` | local, gitignored |

The old files under `eval/embedding/queries/` and `eval/embedding/confirm/`
are never edited; `build.py` pins their sha256.

## Commands (from the repo root)

```
eval/embedding/v2/sample.sh <work dir>          # re-sample; must be byte-identical
python3 eval/embedding/confirm/check_targets.py eval/embedding/v2/new/targets \
    --seed 460 --against eval/embedding --against eval/embedding/confirm
python3 eval/embedding/check_queries.py <corpus> --checkout <work dir>/corpora/<corpus> \
    --eval-dir eval/embedding/v2/new --seed 460 \
    --disjoint-from eval/embedding --disjoint-from eval/embedding/confirm
python3 eval/embedding/v2/build.py              # write queries/*.jsonl
python3 eval/embedding/v2/build.py --check      # verify; prints counts and cross-side overlap
python3 eval/embedding/v2/neardup.py [prefix..] # section 6 review: new texts at token Jaccard >= 0.5
```

## Seed-460 frames (stage 2)

Count per corpus = stage-2 positives x 1.3, rounded up. Frame left after both
studies (fn / type / other): gin 290 / 0 / 6, py-requests 47 / 0 / 97,
ripgrep 2019 / 322 / 108, g-mesh 1457 / 366 / 516, excalidraw 2318 / 22 / 29,
task-tracker-mcp 18 / 0 / 0. task-tracker-mcp has 18 targets, not 20, for its
15 positives.

## Freeze

One commit adds `new/queries/*`, the regenerated `queries/*` and
`docs/results/gm-460-enlarged-eval.md` (each v2 file's sha256 and the
per-language, per-side counts), before any arm runs on v2.
